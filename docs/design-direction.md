# Design Direction

## Desired feel

- The portfolio should feel tech-forward, futuristic, sharp, and high-performance.
- The visual identity should have personality and impact, not a safe corporate tone.
- The experience should feel premium and intentional rather than decorative for its own sake.

## Visual principles

- Favor dark mode as a first-class experience.
- Use contrast, motion, and hierarchy to create impact.
- Keep the UI expressive, but not visually crowded.
- Prefer clean composition with strong focal points instead of many competing elements.

## Motion and interaction

- Motion should communicate polish and confidence.
- Subtle interaction depth is good; noisy or distracting animation is not.
- The existing interactive background can remain a signature element, but surrounding sections should still feel readable and controlled.

## Layout direction

- Use layouts that create emphasis and breathing room.
- Give important statements and proof points enough space to stand out.
- Avoid dense blocks that feel institutional or document-like.

## Color and theme guidance

- Preserve dark mode support when changing sections or adding components.
- Reuse the CSS variable system in `src/app/globals.css` instead of scattering new theme values.
- Visual updates should work with the current purple-accent direction unless a broader redesign is intentional.

## What to avoid

- Avoid a bland corporate portfolio look.
- Avoid academic presentation patterns.
- Avoid visual clutter, too many simultaneous highlights, or effects that hurt readability.

## Good task directions derived from this file

- Redesigning the hero for more visual impact.
- Increasing contrast and hierarchy in key sections.
- Refining animations to feel more premium.
- Making the portfolio feel more futuristic without becoming noisy.
